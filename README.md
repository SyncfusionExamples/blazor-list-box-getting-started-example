# Blazor ListBox Getting Started Example

A comprehensive guide to integrating the [Blazor ListBox](https://www.syncfusion.com/blazor-components/blazor-listbox) component into a Blazor Server application. This example demonstrates the quickest way to get up and running with list selection functionality.

## Overview

The Blazor ListBox is a powerful selection component that enables users to select one or multiple items from a list. This sample demonstrates how to:

- Set up a Blazor Server application with Blazor components
- Create and configure a ListBox with typed data sources
- Bind list data using field mappings
- Style and position the ListBox in your layout

The example includes a working ListBox populated with sample game data, ready to extend with your own features.

## Features

- **Server-side Blazor application** - Built on the latest .NET framework
- **Typed data binding** - Full C# type safety with generic components
- **Responsive layout** - Centered, mobile-friendly design
- **Field mapping support** - Easy customization of display and value fields
- **Hot reload support** - Fast development experience

## Getting Started

### Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-list-box-getting-started-example.git
cd blazor-list-box-getting-started-example
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
